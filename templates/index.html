so how does this work?

this works by using the jev system one model from typesafe ai.

jev isn't an llm. it doesn't generate text. all it does is generate probabilities of choices i give it.

so in context, for every user 10 random nouns are picked from wonder words, jev decides whats the easiest to guess and uses that word.

every time you ask a question jev evaluates if question is yes or no, and if the question means you know what the word is.

we send those results back to the user, and that's the game.
